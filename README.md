# Projekt-Benutzerverwaltung-in-Linux
In dieses Repo Poste ich alles über das Projekt Benutzerverwaltung vom BITLC

Dieses Projekt wurde innerhalb einer Linux Bash via GNU nano 5.6.1 geschrieben

Übersicht:
- Erstellen der verschiedenen Logdateien
- Erstellen des Benutzernamens und Passwort Generierung
- Benutzer anlegung und Speicherung aller erstellten Werte in der Logdatei
- Löschung aller Erstellten Benutzer
